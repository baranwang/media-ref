<Endpoint
  method="POST"
  url="https://api.mediaref.org/mediaref.v1.ChangeRequestService/GetChangeRequest"
/>

## 请求参数 [#request]

| 字段 | 类型   | 说明                                                           |
| ---- | ------ | -------------------------------------------------------------- |
| `id` | string | 必填。变更单 ID，CreateChangeRequest 返回的 `changeRequest.id` |

<Hint>任何密钥都能查任意一张变更单，不限于自己提交的。</Hint>

## 返回内容 [#response]

| 字段                  | 类型          | 说明                                                                                                           |
| --------------------- | ------------- | -------------------------------------------------------------------------------------------------------------- |
| `changeRequest`       | ChangeRequest | 变更单                                                                                                         |
| `liveChangeRequestId` | string        | 这张没生效、但同一部作品同一个页面已经有另一张生效了（比如被驳回后探索 agent 又提交了一次），这里是那一张的 ID |

`ChangeRequest` 里常用的字段：

| 字段                      | 类型                | 说明                   |
| ------------------------- | ------------------- | ---------------------- |
| `id`                      | string              | 变更单 ID              |
| `status`                  | ChangeRequestStatus | 状态，见下表           |
| `target`                  | MediaRef            | 提交时的目标作品       |
| `mediaId`                 | string              | 对上的作品 ID          |
| `namespace` / `nativeId`  | string              | 平台和标准编号         |
| `segments`                | Segment[]           | 提交的分集映射         |
| `conflictReason`          | string              | 和已有记录冲突时的原因 |
| `decisionReason`          | string              | 生效或驳回的原因       |
| `appliedAssociationId`    | string              | 生效后对应关系的 ID    |
| `createdAt` / `updatedAt` | string              | 创建和最后更新时间     |

| 状态                                     | 意思                                |
| ---------------------------------------- | ----------------------------------- |
| `CHANGE_REQUEST_STATUS_PENDING_EVIDENCE` | 正在自动核对                        |
| `CHANGE_REQUEST_STATUS_NEEDS_REVIEW`     | 自动核对拿不准，交给审核 agent 判定 |
| `CHANGE_REQUEST_STATUS_APPROVED`         | 已经生效                            |
| `CHANGE_REQUEST_STATUS_REJECTED`         | 被驳回，原因在 `decisionReason`     |

## 错误 [#errors]

鉴权和限流的错误见[快速开始](/docs/quickstart#errors)。

| HTTP  | 业务错误码                  | 原因                 |
| ----- | --------------------------- | -------------------- |
| `400` | `INVALID_CHANGE_REQUEST_ID` | `id` 不是合法的 UUID |
| `401` | `UNAUTHORIZED`              | 没带密钥             |
| `404` | `CHANGE_REQUEST_NOT_FOUND`  | 没有这张变更单       |

## 代码示例 [#example]

<CodeTabs items={["curl", "TypeScript", "Python", "Go"]}>

```bash
curl https://api.mediaref.org/mediaref.v1.ChangeRequestService/GetChangeRequest \
  -H "Authorization: Bearer $MEDIAREF_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "id": "0193f2c6-9e4a-…" }'
```

```ts
import { createClient } from "@connectrpc/connect";
import { ChangeRequestService, createMediaRefTransport, proto } from "@media-ref/client";

const transport = createMediaRefTransport({ apiKey: process.env.MEDIAREF_API_KEY! });
const changeRequests = createClient(ChangeRequestService, transport);

const { changeRequest } = await changeRequests.getChangeRequest({ id: "0193f2c6-9e4a-…" });
if (changeRequest?.status === proto.ChangeRequestStatus.REJECTED) {
  console.log(changeRequest.decisionReason);
}
```

```python
import os
import requests

res = requests.post(
    "https://api.mediaref.org/mediaref.v1.ChangeRequestService/GetChangeRequest",
    headers={"Authorization": "Bearer " + os.environ["MEDIAREF_API_KEY"]},
    json={"id": "0193f2c6-9e4a-…"},
)
res.raise_for_status()
change_request = res.json()["changeRequest"]
print(change_request["status"], change_request.get("decisionReason"))
```

```go
body := strings.NewReader(`{ "id": "0193f2c6-9e4a-…" }`)
req, _ := http.NewRequest("POST",
	"https://api.mediaref.org/mediaref.v1.ChangeRequestService/GetChangeRequest", body)
req.Header.Set("Authorization", "Bearer "+os.Getenv("MEDIAREF_API_KEY"))
req.Header.Set("Content-Type", "application/json")
res, err := http.DefaultClient.Do(req)
```
